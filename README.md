# Учитель ИИ

Программа для Windows, которая дообучает открытые языковые модели (Qwen, Llama, Mistral и др.) на ваших данных
и сохраняет результат в GGUF для приложения «мини-ИИ» на телефоне.

Собрана из готовых открытых частей: Hugging Face transformers + PEFT (LoRA/QLoRA) + bitsandbytes + datasets + accelerate,
llama.cpp для GGUF. Интерфейс — Electron, движок — локальный сервер на встроенном Python (только 127.0.0.1).

## Что умеет
- Определяет видеокарту NVIDIA, видеопамять, ОЗУ, диск, версию CUDA драйвера и подбирает модель и способ:
  полное обучение / LoRA / QLoRA 4 бита / процессор. Можно выбрать любую модель с Hugging Face.
- Сама ставит всё нужное в `C:\ProgramData\UchitelII` (путь без русских букв и пробелов): встроенный Python 3.12, pip,
  PyTorch с CUDA (cu126 / cu130 по драйверу), библиотеки проверенных версий, llama.cpp.
- Данные: скачивание по ссылке с докачкой, проверкой SHA-256 и свободного места; наборы Hugging Face потоково;
  свои файлы txt, md, pdf, docx, csv, json/jsonl, zip, папки. Очистка, удаление повторов, нарезка, предпросмотр.
- Обучение: готовые настройки и тонкие параметры, прогресс, график loss, пауза/продолжение с контрольной точки, стоп.
- Несколько видеокарт: через `accelerate launch` (указать число видеокарт).
- Результат: слияние LoRA с весами, сохранение в формате HF, экспорт GGUF (Q4_K_M, Q5_K_M, Q8_0, F16), чат «до/после».

## Новое в 1.1.0 — «Своя модель»
- **Ivan GPT**: скачивание весов из релизов приватного репозитория `ivan-gpt` (v2.0 / v1.0) по GitHub-токену. Токен вводится
  в программе и хранится только на этом компьютере, зашифрованным через Electron `safeStorage` (DPAPI Windows); в Python
  и интерфейс не передаётся. Можно выбрать уже скачанный файл (`model.safetensors`, zip, `IvanGPT.apk`) или папку.
- **Перенос без потерь** в Hugging Face `LlamaForCausalLM` (или `Qwen2ForCausalLM` с нулевыми bias) + токенизатор Llama
  из `ivan.model`. RoPE Ivan GPT — чередующиеся пары, у HF — половины: строки Q/K переставляются внутри каждой головы.
  После переноса логиты сверяются с исходным `model.py` (макс. разница ~2·10⁻⁵ в fp32).
- **Рост модели** с сохранением функции: новые слои тождественные (`o_proj = down_proj = 0`), ширина — новые
  размерности остатка нулевые, RMSNorm пересчитан (вес·√(D/D′), eps·D/D′), новые головы и нейроны FFN с нулевым вкладом,
  контекст = `max_position_embeddings`. Экран с размерами под ваше железо (запас 15%), памятью и временем.
- **Архитектуры**: Llama, Qwen2, Qwen3 (QK-norm, GQA), Mixtral (MoE, апсайклинг плотной модели), Qwen3-MoE.
- **Создать новую модель**: архитектура → размер → токенизатор (свой SentencePiece / Ivan GPT / Qwen) → скелет → предобучение.
- **Быстрый движок полного обучения** (`backend/pretrain.py`, в стиле nanoGPT): memmap `.bin`, упаковка без паддинга,
  bf16/fp16 + TF32, SDPA, fused AdamW (или 8-битный), torch.compile только если работает, подбор пачки, одно автоматическое
  уменьшение пачки при нехватке памяти, контрольные точки и продолжение, несколько GPU (DDP / FSDP2, выгрузка в ОЗУ).
- **Источники данных** с лицензиями: дампы Wikimedia (потоково), наборы HF (FineWeb-2, OpenWebMath, StarCoderData…),
  Project Gutenberg, репозитории GitHub с открытой лицензией, файл/архив по ссылке, сайт с соблюдением robots.txt.
- **Экспорт**: GGUF (llama.cpp) и обратно в формат Ivan GPT (`model.safetensors`, `config.json`, `web/model.bin`).

## Сборка
```
npm install
UCH_SIGN_PFX=... UCH_SIGN_PASS_FILE=... npx electron-builder --win nsis portable
```
Проверка движка без Windows: `UCHITEL_HOME=/tmp/u python backend/server.py 18777` и открыть http://127.0.0.1:18777.
